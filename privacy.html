Política de privacidad

Finalidad

rclone-unido es una configuración de OAuth para uso personal que permite al titular conectar cuentas de Google Drive con el software rclone. No es un servicio ofrecido a terceros ni una aplicación web que almacene archivos.

Acceso a datos de Google

Cuando el titular autoriza la conexión, rclone puede acceder a los archivos y metadatos de Google Drive conforme al alcance OAuth autorizado. Dependiendo de los permisos elegidos, puede listar y descargar archivos o también crearlos, modificarlos, moverlos y eliminarlos. Cada cuenta concede o revoca el permiso de manera independiente.

Uso y almacenamiento

Los datos se usan para las operaciones que el titular ejecuta mediante rclone, incluidos listados, copias, sincronizaciones y transferencias. Los tokens de acceso y actualización se almacenan en la configuración local de rclone (rclone.conf) en los equipos donde el titular lo configure. Los datos pueden transferirse a otras ubicaciones que el titular seleccione expresamente al ejecutar una operación; esta web no ejecuta dichas transferencias.

Compartición

La web informativa no recibe archivos de Drive ni tokens OAuth, no dispone de formularios y no incorpora herramientas propias de analítica. No se comercializan datos de usuario. La plataforma que aloje la web puede tratar registros técnicos de acceso según su propia política. El uso de herramientas adicionales conectadas a rclone, si lo hubiera, se rige por su configuración y condiciones independientes.

Seguridad, conservación y retirada del acceso

El titular controla los equipos que almacenan sus credenciales de rclone y debe proteger el archivo de configuración contra accesos no autorizados. Los datos locales permanecen hasta que el titular los borra; esta web no mantiene una base de datos de archivos ni tokens. Puede revocar el permiso en la sección de conexiones de terceros de su cuenta de Google y eliminar las credenciales locales de rclone.

Contacto

Para consultas sobre la configuración OAuth, se puede utilizar el correo de asistencia que aparece en la pantalla de consentimiento de Google.
